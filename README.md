# SortViz - 정렬 알고리즘 시각화 웹 애플리케이션

**SortViz**는 다양한 정렬 알고리즘의 작동 방식을 실시간 애니메이션으로 직관적으로 시각화하여 보여주는 모바일/웹 대응 반응형 웹 애플리케이션입니다. 
복잡한 알고리즘 동작 과정과 원리를 시각적으로 이해하는 데 도움을 주기 위해 제작되었습니다.

## ✨ 주요 기능

- **다양한 정렬 알고리즘 제공:** 버블 정렬(Bubble Sort), 선택 정렬(Selection Sort), 삽입 정렬(Insertion Sort) 지원
- **실시간 애니메이션 시각화:** 상태별 색상 구분(비교, 선택, 정렬 완료)을 통해 진행 상황을 한눈에 확인
- **속도 제어:** 슬라이더 컨트롤을 통해 정렬 애니메이션 속도를 자유롭게 조절
- **상세 설명 및 복잡도 안내:** 선택한 알고리즘의 동작 방식과 시간 복잡도 정보 제공
- **반응형 레이아웃:** 모바일 및 데스크톱 환경 모두에 최적화된 UX/UI 제공
